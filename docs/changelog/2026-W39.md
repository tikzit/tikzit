# 2026-W39 (2026-09-21 – 2026-09-27)

## Added

- **Web-rebuild sprint roadmap** (`docs/sprints/_active/`): an 8-sprint implementation plan for an Astro/TypeScript TikZiT web application — TypeScript TikZ parser/emitter modeled on the native Flex/Bison grammar, Three.js/WebGL canvas, DockView-based workbench, CardPanel/viewlet substrate, Markdown viewlets, Cordis/clm-kernel service orchestration, MCard persistence, preview/export pipeline, and Vitest/Playwright verification. Explicitly scoped as a greenfield plan using the Qt/C++ app as the behavioral reference and differential-test oracle.
- **ZX-calculus example corpus** (`docs/examples/zx-calculus/`): 12 canonical `.tikz` diagrams with generated SVGs, `pqp-zx.tikzstyles` stylesheet, `manifest.json`, gallery page, and `build_examples.py` (pdflatex + pdftocairo).
- **Sprint-00 additions**: verified desktop keyboard/interaction parity table (sourced from `mainmenu.ui`, `tikzscene.cpp`, `tikzview.cpp`), failure-mode/graceful-degradation matrix, and empirical corpus telemetry (node/edge counts, file sizes).
- **CMake build documentation** in `README.md`, including the QtPdf requirement.
- **`docs/changelog/`** directory and weekly entry convention.

## Changed

- **README.md**: added repository layout section describing the native app vs. the planned web-rebuild documentation; noted that sprint documents describe planned work, not implemented features.
- **`.gitignore`**: expanded for CMake build outputs, web toolchain artifacts (`node_modules`, `.astro`, coverage, Playwright reports), LaTeX auxiliary files, and `.dmg` installers.
- **`deploy-osx.sh`**: `macdeployqt` now receives a `-libpath` flag pointing at Homebrew's library directory (`/opt/homebrew/lib` or `/usr/local/lib`) so bundled dependencies resolve on modern macOS installs.
- **Sprint documents**: corrected numerous technical claims against the native source — ordered `GraphElementData` property semantics (first-match lookup), pgfonlayer parse-ignore/emit-only behavior, edge bend/weight model, actual desktop keybindings (`Alt+→`/`Alt+↓` reflect, `Alt+Shift+→`/`Alt+Shift+←` rotate about the origin, `Ctrl+[`/`Ctrl+]` reorder, `Ctrl+Arrow` micro-nudge, `Shift+Arrow` extend selection), clipboard-as-TikZ semantics, and paste placement relative to the existing bounding box. Feasibility gates added for the browser TeX engine and `clm-kernel`/Cordis browser APIs; performance targets reframed as measured budgets rather than guarantees.

## Fixed

- **`CMakeLists.txt`**: added the missing `Pdf` component to `find_package`/link libraries — the preview window includes `QPdfDocument`, so the CMake build previously failed to compile.
- **Lexer/parser token rename** (`src/data/tikzlexer.l`, `src/data/tikzparser.y`): `AT` → `TOKEN_AT` to avoid macro/symbol collisions during code generation.
- **Sprint documents**: repaired control-character corruption in math blocks (`\to`, `\theta`, `\alpha`, `\beta`), fixed broken corpus links, corrected the Monarch tokenizer spec (word boundaries, Monaco-vs-CodeMirror distinction), and clarified that `pdf-lib` requires per-path `drawSvgPath` assembly rather than arbitrary SVG embedding.

- `docs/examples/build_examples.py` continues past individual fixture failures — check its output rather than relying on exit status.
