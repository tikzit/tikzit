# Changelog

Weekly changelog entries for this repository. One file per ISO week, named `YYYY-Www.md` (e.g. `2026-W40.md`).

Each entry summarizes the week's notable changes under conventional headings:

- **Added** — new files, features, documentation, or capabilities
- **Changed** — modifications to existing behavior or documents
- **Fixed** — corrections to code or documentation
- **Notes** — caveats, known limitations, or work intentionally deferred

Entries cover both the native Qt/C++ application and the web-rebuild documentation/workbench under `docs/sprints/` and `src/`.
